# 本机 AI 工作区

工作台的「📁 工作区」默认打开文件管理小标签，使用与服务器文件管理一致的路径栏、工具栏和文件列表。工作区支持文件管理、终端和配置三类小标签，左侧服务器列表不增加入口。

## 使用

1. Windows 选择专门的本机文件夹；Android 使用本机运行组件管理的工作文件区。
2. 点击文件管理工具栏的「⚙ 配置」，在配置小标签中选择目录、启用并保存。Windows未安装Linux时也能管理本机工作区文件。
3. 需要终端或AI执行命令时，在配置小标签点击「安装 Linux 工作区」。第一次才下载固定版本的Alpine和运行组件，支持暂停后继续。工作区统一使用Linux，旧PowerShell配置保留原目录和文件并转换运行方式。
4. 上传文件或文件夹，也可把它们拖到文件列表或目标子目录。保留目录层级，拖拽支持空目录；同名文件报错，不覆盖。Android的「上传文件夹」使用系统目录选择器并通过文件句柄逐个导入。列表支持选择、排序、文本编辑、复制、剪切、粘贴、重命名和删除。
5. 告诉 AI 要处理什么。AI 会知道安装、启用、运行方式及联网状态；没有获得的文件不会被假装读取。

安装和启用是不同操作：保存路径不等于已下载或已启动环境。切换运行方式不会换文件夹；Windows仍使用用户选择的本机目录，Linux内部的路径是 `/workspace`。

## 小标签

文件管理是默认页面。点击「＋」可以另开文件管理或终端小标签，各文件管理标签独立记住浏览路径。固定宽度及关闭位置，支持固定、拖动排序和刷新恢复。

点击文件管理工具栏的「>_ 终端」，或右键文件夹选择「在此处打开终端」，会新建并切换到对应目录的独立终端标签。多个终端共用同一环境与文件，各自的输入、输出和工作目录独立。

文件管理的配置按钮在工具栏里；终端的配置按钮固定在小标签栏右侧，与「＋」并排，标签滚动时位置不变。点击后打开或复用唯一的配置小标签。安装、卸载、启动停止和随软件启动设置都在配置标签里。

## 启动与终端

默认按需启动：首次 AI 命令或手动打开终端时才启动，空闲五分钟后停止。勾选「随软件启动 Linux 环境」并保存，下次打开应用会启动已安装、已启用的环境。下载不会因开启软件自动发生。

切换小标签或切换工作台其他大标签不会关闭终端会话。关闭终端小标签才结束对应会话。Windows在最后一个终端关闭后同步文件；终端打开期间，AI命令会要求先关闭终端，避免两方同时覆盖文件。程序需要的工具可以装在Linux环境中，工作区磁盘保留这些内容供下次使用。

## 两端运行方式

Windows 使用软件管理的 QEMU 和 Alpine 基础系统，无需 WSL、Root 或管理员安装系统组件。环境只使用专属磁盘，原工作文件通过受控同步进入 `/workspace`。文件修改前检查本机哈希；用户同时修改过的文件会保留，不自动覆盖。Linux 删除操作也只同步没有被用户修改的文件。

Android 首次安装一个使用固定 ShellPilot 签名的运行组件，由系统安装界面处理。组件与主应用是独立应用身份，使用签名 Binder 与显式文件句柄协作，不复制主应用的 API Key 和 SSH 资料。PRoot 提供 Linux 运行兼容，不能等同完整虚拟机；执行器限制私人地址、本机接口及工作区外的文件访问，设备检查后才作为可用组件发布。

联网开关默认关闭。Windows Linux 环境通过专用 HTTP/HTTPS 代理联网，直接网络保持关闭，代理拒绝本机和内网地址；Android 执行器限制网络访问。服务器上传下载仍由主应用通过已授权 SSH 主机进行。

## 文件与服务器协作

直接上传：把文件拖到相应服务器的「文件管理」页面。

由 AI 处理后上传：把文件放进工作区或在工作区页面上传，再告诉 AI 目标服务器和远端路径。内置 AI 可以流式上传下载，上传后校验；工具不覆盖远端或本机已有文件，需要修改时先处理实际冲突。工作区工具不会自动开放给外部 MCP。

## 卸载与更新

「卸载运行环境」在当前页面确认，停止运行、关闭 Linux 工作区并删除下载组件，保留工作文件。Windows 专属磁盘继续保留。Android 通过此入口删除展开的 Linux 环境，系统运行组件保留用于保存工作文件；在系统设置里卸载整个运行组件会删除其应用数据，应先导出文件。

普通应用更新不重复下载相同版本组件，也不重建用户磁盘。各组件单独记录版本，安卓服务层更新不会让Windows重新下载QEMU和Alpine。运行组件使用固定下载标签、完整大小和SHA256校验，通过仓库Release下载，提供API入口备用。网络失败显示具体原因，失败文件不当作安装成功。

## 排队、统计与记忆

输出中发送消息会排队，暂停和停止按钮仍显示。点击排队消息取回主输入框；已有草稿会保留，已开始的消息不能再次取回。

回答底部以小字保存统计：

    2026-11-09 03:20 ↑1,200（800） ↓300 12s 25tok/s Provider/Model

缓存命中位于输入数后的括号，完整数字每三位加英文逗号。统计来自服务商实际返回，缺失显示 —；旧回复不补造统计。

记忆保留检索筛选，使用独立滚动的单行列表，支持勾选、编辑、启停和批量删除，不要求主题。自动记忆开关只控制 AI 主动保存，已有启用记忆继续参与回答。
