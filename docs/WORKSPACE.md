# 本机 AI 工作区

在配置页选择一个专门的本机文件夹，勾选启用并保存。聊天输入框旁的「工作区」可以查看这个目录，上传文件、新建或编辑文本、下载生成的文件。你也可以用资源管理器直接把文件放进所选目录。

告诉 AI 要做的事，例如“读取工作区的说明，生成网页文件”或“整理这些文本并写入汇总文件”。AI 可以自行读写工作区，并在其中运行 PowerShell、调用你在该工作区准备的工具。配置中独立控制工作区联网。

Windows 命令由 **AppContainer** 运行。它限制工作区外的私人文件和系统写操作，不继承 ShellPilot 的 API Key、SSH 登录资料或其他秘密环境变量。每次命令使用独立进程组，停止任务、停用工作区或超时会结束相关进程。文件接口仅接受相对路径，拒绝符号链接、目录联接与硬链接；修改已有文件可校验读到的哈希。

启用时只给本模块沙箱标识授予工作文件夹权限，并标记为可供低权限进程运行；上级目录仅授予通行和属性读取，不开放其他文件内容。停用工作区会移除本模块授权并恢复原运行标记。

这是一块本机协作空间，不是完整 Windows 虚拟机。系统程序和库可以为运行命令而读取，AppContainer 也有自己的系统管理缓存；没有获得电脑所有目录的权限。不支持把磁盘根、用户资料根、系统目录或 ShellPilot 配置目录作为工作区。程序需要的文件放在工作区里，安装系统级软件仍由用户在工作区外完成。

工作区第一版用于 Windows，Android 保留现有 SSH、AI 与记忆功能。外部 MCP 暂时不会获得本机工作区工具。工作区路径不随主机备份启用到另一台设备；在新电脑上重新选择本机目录。

## 排队与回答统计

AI 输出中发送新消息会排队，暂停和停止按钮仍显示。点击排队消息会由后台取回到主输入框，修改后重新发送；如果消息已经开始执行，会显示实际状态，避免重复执行。输入框已经有草稿时，取回内容追加到草稿后，保留原文字。

每条回答底部显示一行小字：

    2026-11-09 03:20 ↑1,200（800） ↓300 12s 25tok/s 服务商/模型

括号里是输入缓存命中的 tokens。数字用完整千分位逗号，不使用 k；时间按本机显示。用量来自服务商实际返回，未知值显示 —。时长包含整个任务过程，速度按生成耗时计算，不把暂停时间算进生成速度；多轮工具回答会累加该任务的用量。历史回复保留统计，新功能上线前的旧回复没有统计。

## 简洁记忆

检索与筛选保留。列表每行是内容，左侧勾选与编辑图标，右侧启用中／关闭中；列表独立滚动，选中后批量删除。添加记忆只需写内容，主题不再必填。旧记录的内容和开关保留。

自动记忆总开关仍只控制 AI 是否主动保存，已有启用记录继续参与回答。AI 可用记录 ID 更新自己以前的内容，手动维护和停用的记录受到保护，不自动覆盖或重新启用。
