# 数据、权限与隐私

[项目首页](../README.md) · [报告安全问题](../SECURITY.md)

## 本地数据

Windows 桌面应用默认使用 `%APPDATA%\ShellPilot`；Android 数据在应用内部目录；独立 Rust 服务端默认使用当前目录下的 `data/`。`SHELLPILOT_DATA` 可覆盖服务端/MCP 数据目录。

| 文件 | 内容 |
| --- | --- |
| `hosts.json` | 主机地址、用户名、密码或密钥相关信息 |
| `settings.json` | 模型服务商、API Key、参数和权限 |
| `chats.json` | 用户消息、模型回复及工具结果 |
| `memories.json` | 长期记忆、参与回答开关和来源 |
| `agent-jobs.json` | 当前及排队任务，重启后以暂停状态恢复 |
| `audit.log` | 命令与操作记录 |
| `trusted-host-keys.json` | 已保存服务器指纹 |
| `observed-host-keys.json` | 待处理的服务器指纹变化 |
| `window-state.json` | 桌面窗口状态 |
| `runtime.json` | 主窗口供 MCP 本机联动使用的信息 |

JSON 文件不能当作加密保险箱；有权限读取应用目录的程序可以读取其中内容。导出备份使用用户提供的密码进行 AES-256-GCM 加密，备份密码不会替代本地目录的访问控制。

## 什么会发给模型

AI 使用你配置的模型服务商。用户消息、主机名称/地址、性能信息和工具输出会进入模型上下文。主机工具列表不返回 SSH 凭据，登录密码和私钥不会被主动插入系统提示；但你自行发送秘密，或让工具读取包含秘密的文件，仍可能把内容传给模型。不能承诺 AI “永远看不到任何密钥”。

MCP 外部客户端有自己的消息、模型和本机访问策略。ShellPilot 的 MCP 授权控制服务器工具，不代表开放整台电脑文件访问。

## SSH 身份

首次连接自动保存当时服务器提供的公钥指纹，之后自动比对。首次使用没有独立核实真实服务器身份；后来发生变化会暂停，要求在该机器内容区处理。不要只为了清除错误而信任不明变化，应核实是否重装或更换 SSH 密钥。

## 执行模式

只读与自动模式基于本地命令策略；这不是隔离任意 Shell 脚本的完整沙箱。完全托管按用户授权直接执行命令，包括删除等高风险操作。授权哪台服务器、使用哪个模式应与任务匹配。

停止 AI 会关闭执行中的 SSH 通道，但已脱离会话的后台程序可能继续运行，需检查实际状态。文件修改工具执行预览、旧哈希检查、备份与新哈希校验；备份不自动完成业务回滚。

## 分享诊断

公开 Issue 只分享必要的错误、步骤和脱敏截图。不要附原始配置、未加密的主机列表、私钥、API Key 或完整聊天日志。已泄露的密码/令牌应先撤销或轮换，删除截图不能使凭据重新安全。
